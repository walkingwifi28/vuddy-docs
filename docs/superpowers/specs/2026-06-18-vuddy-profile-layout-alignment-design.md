# Vuddy 営業資料 レイアウト統一設計

## 目的

`pages/service-introduction-materials/vuddy/index.html` の指定スライドを、`pages/service-introduction-materials/profile-vuddy/index.html` の対応スライドと同じ視覚構造・装飾へ揃える。

## 対象

- 2ページ目: 右側の「変化」を示す図のみ
- 4、6、7、11、13、17ページ目: ページ全体のレイアウトと装飾

## 実装方針

- 対応する `profile-vuddy` スライドのHTML構造、クラス、余白、配色、枠線、角丸、文字階層を基準にする。
- `vuddy` 側の見出し、本文、比較内容、料金説明、CTA文言は維持する。
- 対象ページだけに必要なスタイルを反映し、指定されていないページの見た目は変更しない。
- 既存の17ページ構成、Reveal.js操作、PDF出力、ロゴ、相対アセットパスを維持する。
- 新しい画像、依存関係、JavaScript機能は追加しない。

## 検証

- トップレベルのスライドが17枚のままであることを確認する。
- 指定ページを参照版と同じ画面サイズ・スライド位置で比較する。
- 文字切れ、重なり、はみ出し、余白・枠線・角丸・文字サイズの不一致を確認する。
- 対象外ページ、Reveal.js操作、PDFボタン、ブラウザコンソールに回帰がないことを確認する。

## 対象外

- 本文の改稿
- 指定外ページの再設計
- 新規素材や機能の追加
