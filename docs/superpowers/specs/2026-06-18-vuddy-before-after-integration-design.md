# Vuddy Comparison・Example統合設計

## 目的

サービス紹介資料の11ページ「Comparison」と12ページ「Example」で重複している比較説明を、1ページのBefore/After表現に統合する。Vuddyの機能差だけでなく、導入によって業務がどう変わるかを一連の流れとして伝える。

## 対象

- `pages/service-introduction-materials/vuddy/index.html`
- 現在の11ページ「Comparison」を統合ページへ変更する。
- 現在の12ページ「Example」を削除する。
- 以降のスライドは1ページずつ繰り上がる。

## 情報構成

統合ページは「配信 → 視聴 → 分析 → フォロー」の業務フローに沿った4項目で構成する。各項目内にBeforeとAfterを並べ、従来の課題とVuddy導入後の状態を直接比較できるようにする。

| 項目 | Before | After |
| --- | --- | --- |
| 配信 | 一律の動画・資料を送付 | URL・QR・Webで選べる動画を配信 |
| 視聴 | 決められた情報を受動的に閲覧 | 関心に応じて情報を選択 |
| 分析 | 反応が見えず感覚で判断 | 選択率・離脱・遷移・CTAを分析 |
| フォロー | 全員に同じ内容で対応 | 関心に応じた提案・CTA・改善へ接続 |

## 表示設計

- 既存のBefore/Afterカードレイアウトを再利用し、4カード構成を維持する。
- ページ見出しは、導入前後の変化が端的に伝わる内容へ変更する。
- カードの順序で業務フローを表現し、新しいコンポーネントや大規模なCSS変更は追加しない。
- 既存のロゴ、余白、配色、レスポンシブ・印刷設定を維持する。

## 変更しない範囲

- 他ページの文言やレイアウト
- Reveal.jsの設定
- 既存のユーザー変更
- 資料全体のデザインシステム

## 検証

- トップレベルのスライド数が1ページ減っていること。
- 「Comparison」の重複ページが残っていないこと。
- 統合ページに4項目すべてのBefore/Afterが存在すること。
- HTMLの開始・終了タグが対応していること。
- 利用可能な既存テストを実行し、変更による回帰がないこと。
