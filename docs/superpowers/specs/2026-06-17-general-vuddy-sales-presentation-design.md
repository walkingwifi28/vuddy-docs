# Vuddy 統合営業資料 設計仕様

## 目的

既存の名刺用途向け Vuddy 営業資料を、汎用営業資料、法人向け提案資料、サービス紹介資料の役割を一つに統合した内容へ刷新する。

Vuddy の仕組みや機能を説明するだけでなく、営業活動、ホームページ上の接客、対面後のフォローという複数の活用場面を示し、閲覧者が自社での利用方法と導入後の運用を具体的に想像できる資料にする。

## 対象読者

- 顧客ごとに適切な情報を届け、商談前後の反応を把握したい法人営業担当者・営業責任者
- ホームページ上でサービスの魅力や人柄を伝え、問い合わせや予約につなげたい経営者・マーケティング担当者
- 展示会、交流会、名刺交換など、対面接点後のフォローを改善したい事業者
- Vuddy の機能、活用方法、費用、導入手順をまとめて確認したい導入検討者

## 中核メッセージ

Vuddy は、視聴者が知りたい情報を自分で選べるインタラクティブ動画と、その選択・視聴・行動データの分析を組み合わせ、情報提供から次の行動、改善までを一つの流れにするサービスである。

資料全体では次の価値を一貫して伝える。

1. **伝える** — 動画、音声、分岐、ボタンを組み合わせ、文章や静止画だけでは伝えにくい魅力を表現する。
2. **選べる** — 視聴者が課題や関心に合わせて、機能、事例、料金、導入方法などを選択できる。
3. **つなげる** — 動画内 CTA から問い合わせ、予約、資料請求、デモ相談などの次の行動へ誘導する。
4. **分かる** — 視聴、選択、遷移、離脱、CTA 反応から、視聴者の興味関心を把握する。
5. **改善する** — 分析結果を営業フォロー、コンテンツ、導線、訴求内容の改善に活用する。

## 情報設計

既存ページと同じ 17 スライド構成を維持し、前半でサービスの共通価値、中盤で機能と用途、後半で導入判断に必要な情報を提示する。

1. **表紙** — Vuddy サービス紹介資料であることを明示する。
2. **導入メッセージ** — 「一方的に見せる」情報提供を「相手が選べる」体験へ変える価値を提示する。
3. **課題** — 相手ごとに関心が異なること、反応が見えないこと、説明が繰り返されることを示す。
4. **解決策** — 選べる動画体験と分析を組み合わせた Vuddy の解決方法を示す。
5. **運用フロー** — 準備、分岐設計、公開・配信、分析、改善の流れを説明する。
6. **視聴体験** — 視聴者が「選ぶ・理解する・行動する」体験を画面モックアップで示す。
7. **主要機能** — 動画内ボタン、分岐シナリオ、視聴分析、URL・QR・Web 配信を整理する。
8. **分析** — 視聴完了率、選択率、遷移、離脱、CTA クリックなどの確認項目を示す。
9. **活用シーン** — 法人営業、ホームページ、展示会・交流会、採用・案内の用途を並列に示す。
10. **導入メリット** — 理解促進、関心把握、行動促進、継続改善の効果を整理する。
11. **従来手法との比較** — 一律の動画・資料・通常の Web ページと Vuddy の違いを比較する。
12. **活用例** — 配信、視聴・選択、分析、フォロー・改善までの具体的な一連の流れを示す。
13. **料金** — 初期制作費と月額利用料の考え方を示し、個別見積もりへ接続する。
14. **導入プロセス** — ヒアリングから公開後の改善までの伴走範囲を説明する。
15. **よくある質問** — 既存動画、スマートフォン、分析、制作依頼、導入期間、配信方法を扱う。
16. **会社情報** — 株式会社 VARISTA と問い合わせ先を掲載する。
17. **次の行動** — デモ・活用相談への CTA と、相談時に用意する情報を提示する。

## 活用シーンの配分

資料全体を特定用途に固定せず、次の三つを同じサービス価値から派生する代表例として扱う。

- **法人営業** — 商談前の情報提供、顧客による機能・事例・料金・セキュリティの選択、閲覧データを踏まえたフォロー。
- **ホームページ活用** — サービス、人柄、事例、料金、FAQ の選択型案内と、問い合わせ・予約への誘導。
- **対面後フォロー** — 名刺、QR、展示会、交流会からの視聴と、関心に応じた継続接点づくり。

名刺は有効な一用途として残すが、資料全体の前提にはしない。見出しや中核説明では「顧客」「視聴者」「相手」を用い、用途固有の表現は活用シーンと活用例に限定する。

## デザイン方針

- `pages/service-introduction-materials/vuddy/index.html` の配色、タイポグラフィ、カード、図表、Reveal.js 操作を踏襲する。
- 16:9 の営業プレゼンテーションとして、デスクトップ、スマートフォン、PDF 出力で破綻しない構成を維持する。
- 既存の Vuddy ロゴ、VARISTA ロゴ、PDF ダウンロードボタン、フッターロゴを維持する。
- 各スライドは一つの営業メッセージに絞り、見出しを短くする。
- 活用シーンは用途間に優劣をつけず、アイコン、カード、短い例示で比較しやすくする。
- 分析画面の数値は効果保証と誤認されないよう `Sample` 表示を維持する。
- 新しい外部画像や依存関係は追加せず、既存資産と HTML/CSS の図解で完結させる。

## 実装方針

- `pages/service-introduction-materials/vuddy/index.html` を直接改稿する。
- 既存の 17 スライド、Reveal.js 初期化、レスポンシブ CSS、印刷用 CSS、PDF ダウンロード処理を維持する。
- 表紙から CTA までの見出し、本文、カード、比較表、分析指標、FAQ を統合用途向けに改稿する。
- 視聴体験は既存のスマートフォン表示を活用し、用途に依存しない選択体験へ変更する。
- 外部ビルド工程や JavaScript の新規機能は追加しない。

## エラー処理

- ロゴ読み込み失敗時の既存フォールバックを維持する。
- 外部フォントが読み込めない場合も、既存のシステムフォントで判読可能にする。
- PDF 生成時に一時的な URL パラメータを使用する既存動作を維持する。
- デモ表示にネットワーク依存がある場合も、周辺の説明だけでスライドの意図が分かる構成にする。

## 検証方針

- HTML が解析可能で、トップレベルのスライドが 17 枚あることを確認する。
- Reveal.js 初期化、前後移動、キーボード操作、スライド番号が機能することを確認する。
- PDF ダウンロードボタンと印刷レイアウトが維持されていることを確認する。
- 「法人営業」「ホームページ」「展示会・交流会」の三用途が資料内に含まれることを確認する。
- 「選べる体験」「分析」「CTA」「改善」の中核価値が資料全体に含まれることを確認する。
- 名刺用途だけを前提とする見出しや説明が残っていないことを確認する。
- デスクトップ幅とスマートフォン幅で文字切れ、重なり、横方向のはみ出しがないことを確認する。
- ブラウザコンソールにページ起因のエラーがないことを確認する。

## 対象外

- 新しいサービス機能、料金体系、効果実績の追加
- Vuddy 本体や分析画面の機能改修
- 新規画像素材、動画素材、ロゴの制作
- 既存の派生資料 `sales-vuddy`、`profile-vuddy` の改稿
