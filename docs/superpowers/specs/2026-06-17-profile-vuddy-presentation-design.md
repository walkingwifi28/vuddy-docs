# ホームページ活用向け Vuddy 営業資料 設計仕様

## 目的

既存の名刺用途向け Vuddy 営業資料を基に、Vuddy をホームページ上の接客・訴求コンテンツとして活用する BtoC 事業者・小規模事業者向け営業資料を作成する。

資料では、通常のホームページより豊かな表現で強い第一印象を残せること、訪問者が知りたい情報を選べること、その反応を分析して問い合わせ導線やコンテンツを改善できることを一貫して伝える。

## 対象読者

- サロン、スクール、クリニック、飲食店、宿泊施設など、予約・来店型の BtoC 事業者
- 士業、コンサルタント、講師、クリエイターなど、人柄や専門性が選定理由になる個人事業主
- 商品やサービスの魅力を文章と静止画だけでは伝えきれない小規模事業者
- 専任の Web 担当者を置かず、少ない運用負荷で問い合わせ・予約を増やしたい経営者

## デザイン方針

- `pages/service-introduction-materials/vuddy/index.html` の配色、タイポグラフィ、カード、図表、Reveal.js によるスライド操作を踏襲する。
- 既存資料と同じ 16:9 の営業プレゼンテーションとして、デスクトップ・スマートフォン・PDF 出力で破綻しない構成にする。
- 新規の画像素材には依存せず、CSS と既存ロゴ、図表、デモ用 iframe で訴求する。
- 見出しは短く、各スライドは一つの営業メッセージに絞る。

## 中核メッセージ

1. **表現力** — 動画、音声、分岐、演出を組み合わせ、文章と静止画中心のホームページよりサービスの魅力や空気感を豊かに伝えられる。
2. **第一印象** — ファーストビューや重要ページに Vuddy を配置し、訪問直後に強い印象と理解を生む。
3. **選べる体験** — 訪問者が「サービス」「事例」「料金」「よくある質問」など、関心に合わせて情報を選べる。
4. **行動導線** — 動画内 CTA から問い合わせ、予約、資料請求、採用応募などへ直接誘導できる。
5. **分析と改善** — 視聴、選択、遷移、離脱、CTA 反応を確認し、ホームページの訴求内容と導線を改善できる。

専門的な Web マーケティング体制を前提にせず、限られたページ数と運用負荷でも、事業者の人柄、サービスの雰囲気、利用後のイメージを伝えられることを重視する。

## スライド構成

1. 表紙
2. ホームページを「見る」から「体験する」へ変える導入メッセージ
3. 通常のホームページが抱える課題
4. Vuddy による解決策
5. 制作・埋め込み・分析・改善の運用フロー
6. 訪問者が知りたい情報を選ぶ視聴体験
7. ホームページ活用を支える主要機能
8. 視聴・選択・CTA の分析イメージ
9. トップページ、サービス紹介、事例、採用などの活用シーン
10. 表現力、理解、行動、改善の導入メリット
11. 通常のホームページとの比較
12. 導入前後の活用例
13. 料金
14. 導入プロセス
15. よくある質問
16. 会社情報
17. デモ相談への CTA

## コンテンツ要件

- 名刺交換や紙の名刺を前提とした表現は使用しない。
- 「普通の HP」を営業資料内では「通常のホームページ」または「文章・静止画中心のホームページ」と表現する。
- 表現力と第一印象を、冒頭・課題解決・比較・導入メリットの複数箇所で具体的に訴求する。
- 分析指標はアクセス数だけでなく、視聴完了率、選択率、遷移、離脱、CTA クリックを扱う。
- CTA は問い合わせ、予約、資料請求などホームページ上の成果地点へ接続する。
- 活用例は、来店予約、体験申込、相談予約、問い合わせなど BtoC・小規模事業者に身近な成果地点を中心にする。
- 数値は効果保証と誤認されないよう、分析画面の例示には `Sample` を明記する。

## 実装方針

- 出力先は `pages/service-introduction-materials/profile-vuddy/index.html` とする。
- 既存ページを土台として HTML、CSS、Reveal.js 初期化、PDF ボタンを維持する。
- 既存の相対アセットパスとデモ iframe を再利用する。
- 見出し、本文、カード、分析項目、比較表、FAQ、CTA をホームページ用途向けに全面改稿する。
- 外部ビルド工程や新規依存関係は追加しない。

## 検証方針

- 出力ファイルが存在し、HTML として解析できること。
- 全 17 スライドが表示され、名刺用途の残存文言がないこと。
- 主要訴求である「表現力」「第一印象」「選べる体験」「分析」「CTA」が資料内に含まれること。
- Reveal.js の初期化、前後移動、PDF ボタン、デモ iframe が機能すること。
- デスクトップ幅とスマートフォン幅で、文字切れ・重なり・横方向のはみ出しがないこと。
- ブラウザコンソールにページ起因のエラーがないこと。
