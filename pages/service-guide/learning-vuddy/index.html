Introduction

受講者ごとに、
必要な学びを届ける。

Vuddyは、受講者が接客マナー、商品知識、クレーム対応など自分に必要な内容を選びながら学べる教育コンテンツを作成・配信・分析できるインタラクティブ動画サービスです。

Problem

一律の研修動画だけでは、受講者ごとのつまずきが見えません。

!

理解度のばらつきを把握しにくい。
集合研修や長い動画だけでは、どこで迷ったのかが見えにくい。

!

苦手な場面を選んで復習しにくい。
接客、商品説明、クレーム対応など、必要な内容が受講者ごとに異なる。

!

質問や理解度チェックが分散する。
動画、テスト、質問フォームが分かれていると、学習状況を追いにくい。

!

研修後のフォローが属人的になる。
担当者の感覚で追加説明を行い、教材改善に必要なデータが残りにくい。

Solution

Vuddyは、選べる学習体験と分析で課題を解決します。

受講者が必要な内容を選べる

受講者が「基本ルール」「実務シーン」「よくあるミス」「確認テスト」から、理解度や職種に合う内容を選べます。

つまずきと改善点をデータ化

視聴完了率、選択肢のクリック、離脱、理解度チェック、質問内容を確認し、教材とフォローを改善できます。

一律の研修動画から、受講者自身が選び、教育担当者が反応を把握できる学習体験へ。Vuddyが研修の定着を支援します。

Overview

教材準備・配信・分析までを一つの流れで運用できます。

1

動画を準備

接客、商品知識、クレーム対応など、テーマ別の研修動画を整理します。

2

分岐を設計

基本、事例、確認テスト、質問フォームへの流れを目的に合わせて設定します。

3

受講者へ配信

研修案内、社内ポータル、フォロー連絡で公開URLを案内します。

4

反応を分析

視聴完了率、選択率、離脱、回答内容、質問内容を確認します。

5

教材を改善

つまずきやすいテーマをもとに、復習導線と教材内容を見直します。

Viewer Experience

受講者は、苦手な場面や理解度に合わせて学習を進められます。

選べる

基本、実務シーン、よくあるミスなどを自分で選べます。

確認できる

理解度に応じて復習や確認テストへ進めます。

質問できる

動画内フォームから不明点を教育担当者へ送れます。

受講者が自分に必要な学習ルートを選ぶことで、実務に近い場面を短く確認し、次の行動まで進めます。

Features

機能は、受講者ごとの理解と次の学習行動を生むために設計されています。

Feature 01

動画内ボタン

動画上に選択肢やCTAを配置

学習テーマや理解度に合わせた導線を作れる

Feature 02

分岐シナリオ

選択内容に応じて次の動画へ遷移

基本、事例、復習、確認テストを出し分けられる

Feature 03

視聴分析

視聴完了率・離脱・回答を確認

つまずきやすい教材をデータで判断できる

Feature 04

URL・QR配信

研修案内や社内ポータルでURLを共有

集合研修後の復習教材として手軽に配信できる

主な確認指標

  • 視聴完了率：教材が最後まで届いているか
  • 確認テスト回答率：学習後の確認行動につながっているか
  • 理解度スコア：苦手なテーマがどこにあるか
  • 再視聴率：復習が必要な場面を把握できるか
Use Cases

研修プロセスの各接点で、受講者に合う学習体験を届けられます。

新入社員研修

基本ルール、接客マナー、商品知識を短い動画で分岐しながら学べるようにする。

実務前フォロー

配属前に苦手な場面を確認し、実務に近いケースを繰り返し見られるようにする。

クレーム対応研修

状況別の対応例へ分岐し、選択と確認テストで理解度を確認する。

教材改善

離脱や質問が多いテーマを確認し、説明順序や復習導線を改善する。

FAQ

よくある質問

社内研修やeラーニングで共有できますか？

はい。公開URLを研修案内、社内ポータル、フォロー連絡などで共有できます。

既存教材を活用できますか？

はい。既存動画、スライド、確認テスト、FAQをもとに、分岐やCTAを設計できます。

スマートフォンでも見られますか？

はい。店舗スタッフや現場担当者がスマートフォンから復習しやすい体験を設計できます。

分析データは何を確認できますか？

視聴完了率、選択肢クリック、遷移、回答内容、離脱、質問導線などを確認できます。

動画制作も依頼できますか？

素材の有無や制作範囲に応じて、構成作成から制作支援までご相談可能です。

小さく始められますか？

はい。接客マナーや商品知識など、1テーマの教材から開始できます。
